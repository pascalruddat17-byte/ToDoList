# GitHub Pages Start

Diese App ist fuer GitHub Pages vorbereitet.

## Was wichtig ist

- GitHub Pages hostet den Ordner `docs`.
- Die App speichert Aufgaben, Kategorien und Farben lokal im Browser auf deinem Handy.
- Der PC muss danach nicht an sein.
- Fuer kostenlose Nutzung am besten ein oeffentliches GitHub Repository verwenden.

## Schritte

1. Erstelle auf GitHub ein neues oeffentliches Repository.
2. Push diesen Projektordner in das Repository.
3. Oeffne auf GitHub `Settings` -> `Pages`.
4. Stelle als Source `GitHub Actions` ein.
5. Warte kurz, bis der Workflow `Deploy GitHub Pages` fertig ist.
6. Oeffne den angezeigten Pages-Link auf deinem Handy.
7. Fuege die Seite ueber den Browser zum Home-Bildschirm hinzu.

Wenn du die GitHub CLI installierst oder den GitHub Connector aktivierst, kann Codex den Push spaeter direkt fuer dich machen.
